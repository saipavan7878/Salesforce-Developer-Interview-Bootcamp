# Day 3 Reflection

Today I learned how to choose between Validation Rules, Flow, and Apex Triggers based on the business requirement.

I implemented a Record-Triggered Flow for Application automation, created Validation Rules for data quality, and added automatic Offer Letter creation when an Application becomes Selected.

I also learned that declarative automation should be preferred when it can solve the requirement, while Apex is more suitable for complex logic and integrations.

I'm still improving my understanding of Salesforce automation execution order and how multiple automation tools interact in the same transaction.
