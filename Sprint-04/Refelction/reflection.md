# Day 4 Reflection

Today I learned how Lightning Web Components work and how HTML,
JavaScript and the Meta XML file work together to create a Salesforce
user interface.

I built and deployed the `placementHome` LWC, used data binding,
handled button clicks, changed application status using JavaScript,
and created a basic Placement Management dashboard.

I also learned that LWC handles the user interface while Apex is used
for backend logic and database operations.

I am still improving my understanding of how LWC will communicate with
Apex and Salesforce data.
