# LWC Interview Questions

## 1. What is Lightning Web Components?

Lightning Web Components (LWC) is Salesforce's modern UI framework
based on web standards such as HTML and JavaScript. It is used to build
reusable and maintainable user interfaces.

## 2. Why did Salesforce introduce LWC?

Salesforce introduced LWC to provide a modern UI framework based on
standard web technologies and to build reusable, fast and maintainable
components.

## 3. Difference between LWC and Aura

LWC is based on modern web standards such as HTML and JavaScript,
whereas Aura Components use the Aura framework.

LWC is designed around standard web platform features and a simpler
component model.

## 4. What are the three files inside an LWC?

The three main files are:

- HTML file – defines the user interface.
- JavaScript file – contains logic, variables and event handling.
- Meta XML file – controls component configuration and where it can be
  used.

## 5. Why is JavaScript required?

JavaScript is used to implement component logic, variables, events,
button actions and user interactions.

## 7.can LWC directly execute SOQL?

No. LWC does not directly execute SOQL. Salesforce data access is
normally performed through Apex or supported Salesforce data services.

## 8. Why does LWC need Apex?

LWC uses Apex when server-side processing, database operations,
complex business logic or other backend operations are required.

## 9. Where is the component deployed?

An LWC can be deployed to Salesforce Lightning Pages such as App Pages,
Home Pages and other supported Lightning experiences, depending on its
meta XML configuration.
