# Part 1 – Think Before Coding

## 1. Why do users need a graphical interface?

Users need a graphical interface to interact with an application
visually and easily instead of working directly with code or database
queries.

## 2. Why can't users directly execute SOQL queries?

SOQL is used to query Salesforce data. Users should interact with the
application through a user interface instead of directly executing
database queries.

## 3. Why is JavaScript required in LWC?

JavaScript is used for component logic, variables, events, user
interactions, and communication.

## 4. What responsibilities belong to the UI?

The UI is responsible for displaying information, accepting user input,
handling user interactions, and presenting data to the user.

## 5. Which responsibilities should remain in Apex?

Apex should handle backend logic, database operations, complex business
logic, and other server-side responsibilities.
