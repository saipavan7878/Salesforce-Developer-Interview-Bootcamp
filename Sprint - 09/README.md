# Day 9 – Lightning Web Components

## Overview

Day 9 brought the Placement Management System to the user interface
through Lightning Web Components (LWC).

The main practical feature was an **Eligible Jobs** component that
allows a student to view suitable placement opportunities and inspect
job details.

---

## Objective

The goal of Day 9 was to connect the existing Salesforce backend
architecture with a user-facing Lightning Web Component.

The component was developed incrementally:

```text
Create Component
      ↓
Render Component
      ↓
Hard-Coded Job Card
      ↓
JavaScript Data Binding
      ↓
Multiple Jobs
      ↓
Real Salesforce Data
      ↓
Eligibility Logic
      ↓
View Job Details
