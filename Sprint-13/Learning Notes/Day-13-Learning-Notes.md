# Day 13 – Salesforce Security and Access Control

## Objective

Sprint 13 focused on securing the Placement Management System through
Salesforce's layered security model.

The main concepts covered were:

- Authentication and authorization
- Profiles
- Permission Sets
- Roles
- Object-level security
- Field-Level Security
- Record-level security
- Organization-Wide Defaults
- Sharing Rules
- Role Hierarchy
- Apex sharing behavior
- CRUD and FLS
- Least privilege
- Security testing
- Secure integrations
