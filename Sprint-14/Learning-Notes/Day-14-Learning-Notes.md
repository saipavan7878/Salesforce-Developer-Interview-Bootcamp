# Day 14 – Final Salesforce Application Review

## Objective

Sprint 14 focused on taking the Student Placement Management System from
an individual Salesforce project toward a production-ready application.

The final sprint brought together:

- Salesforce data modelling
- Apex
- SOQL
- Triggers
- LWC
- Flow
- Asynchronous Apex
- Integration
- Security
- Testing
- Debugging
- Git and deployment
- Technical explanation

The goal was not only to build features, but to prove that the complete
application can be explained, tested, secured and improved.
