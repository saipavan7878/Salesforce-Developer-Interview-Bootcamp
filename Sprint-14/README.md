# Sprint 14 – Final Salesforce Application Review

## Overview

Sprint 14 is the final capstone review of the Student Placement Management
System.

The purpose of this sprint is to bring together the major concepts learned
throughout the project and demonstrate that the application can be built,
explained, tested, secured, debugged and improved.

The final review covers:

- Salesforce data model
- Flow and automation
- Apex
- SOQL
- Triggers
- Lightning Web Components
- Asynchronous Apex
- External integration
- Security
- Testing
- Debugging
- Git and deployment
- Technical explanation

---
