# Day 2 Learning Notes

## Apex Collections

### List
A List stores an ordered collection of values and can contain duplicates.

### Set
A Set stores unique values and automatically removes duplicates.

### Map
A Map stores key-value pairs and allows records to be retrieved efficiently using a key such as an Id.

## Governor Limits

Salesforce limits database operations and other resources within a transaction.

## Bulkification

Bulkification means writing Apex so that it can process many records efficiently instead of performing SOQL or DML inside loops.

## Asynchronous Apex

Learned that @future methods execute asynchronously and can be monitored through Apex Jobs.

## LWC

Learned that Lightning Web Components can communicate using public @api properties and custom events.
