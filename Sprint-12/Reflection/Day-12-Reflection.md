
# Day 12 Reflection

Day 12 changed my understanding of what it means to build a professional
Salesforce application.

Before this sprint, I mainly thought of the Salesforce org as the place
where the application existed. This sprint showed me that the org is only
one environment. The source-controlled repository is the development
record.

Git made that distinction practical.

I learned how branches isolate changes, how commits create a development
history, how pushes share work, and how Pull Requests provide a structured
review process.

The Pull Request workflow was especially useful because it introduced a
professional feedback loop:

```text
Feature
  ↓
Pull Request
  ↓
Review
  ↓
Improvement
  ↓
Merge
