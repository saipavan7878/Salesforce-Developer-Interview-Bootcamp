# Challenges – Sprint 01

## 1. Developer Console
Initially, the Developer Console was slow to load, which made Apex development difficult.

## 2. Duplicate Apex Component
I received a duplicate-value error because I attempted to create an Apex component that already existed. I learned to open and edit the existing component instead.

## 3. Trigger Testing
I initially had difficulty understanding where to test the trigger. I learned that the trigger should be tested by creating or updating records through Salesforce.

## 4. SOQL Query Execution
The Query Editor initially continued displaying the previous query results. I learned to select the new query and execute it before checking the output.

## 5. Validation Testing
Testing the CGPA rule required using a student whose CGPA was below the job's minimum requirement. Using Priya with CGPA 7.50 successfully triggered the validation.
